# The Last Bell — 入口ページ（文化祭ホラー出し物）

文化祭（日本・学校）向けのホラー脱出ゲームの**入口ページ**です。
Google Sites の埋め込み（iframe）／GitHub Pages での公開を前提にした、**1ファイル完結（シングルHTML）**構成です。

### 演出の流れ（扉を巡る2段階）
1. **開幕**：会場名 → **和紙の掛け軸**が**中央から巻物のように開く**と、天辺のベルがゆらりと揺れ出し、**THE LAST / BELL** の二段が紙面に現れる（BELL は特大の血朱）→ 転写注「ザ・ラストベル ― 最後の鐘」→ 落款「**時は満ちた**」（満のみ朱）→ 朱印「呪」。続いて**序ノ一・二**（開く前の導入）が語られ、その後に扉ボタンが現れる（場所＝旧校舎・最奥の扉／制作＝一年三組）。右下には**風鈴**が無風で静かに吊るされている。
1'. **登場（開幕）中**：まだ現れていない扉・風鈴・ベルは**操作できない**（現れてから触れる）。風鈴は**紙が開き切ってから**吊るし下がる。
2. **1度目のクリック**：画面がわずかに暖色に傾き、銘板も**血の気を帯びてゆっくり染まる**（9秒超の緩い変化）。左右の端書きが囁き始め、悪寒が走る。天辺から**血が少しずつ滴り始める**。風鈴に**微風**が吹き、小さく不気味な音を立て始める。※警告直後の連打は約0.9秒待たされ、振れの演出を飛ばせない。
3. **2度目のクリック**：扉が開く。背景の細部が血に染まる（血の月／窓灯りが紅／門口の紅光／提灯・霧）＋ 掛け軸は**和紙ごと血に染まり**（ゆっくり滲む）、**軸の下辺から血が垂れ始める**。右上に符紙型の**残り刻限 15:00→00:00**（分:秒、残り1分で明滅が速くなる）。続きの物語（序ノ三〜五）が語られる。符札・光塵も解き放たれる。風鈴は**暴風**に煽られて鳴り止まない。（クリック波紋はクリック地点を中心に拡がる）
2'. **警告中（1度目以降）**：夜風が立ち始め、鈴がときどき**微かに震える**（まだ鳴らない）。**風鈴**も小さくチリンと鳴る（7〜11秒おき・音量はごく小さく不気味に）。
3'. **呪縛後**：低い唸りと**心音**が重なり、鈴が**ひとりでにチンと鳴る**（約4秒おきの不規則な自鳴）。
4. **00:00**：ベルが**キーン・コーン**と鳴り響く（WebAudio 合成＝音源ファイル不要）＋鐘体が震え音の輪が広がる。その後も低い唸りだけが残る。

> **スマホ（タッチ端末）＝ Bプラン軽量モード**：開幕を約3割短縮／掛軸 64vw／序文はやや大きめ／ボタンは大きく押しやすい。背の低い端末ではさらに詰めて収まる。

### 導入文（ページ内に表示）
> この学校には、昔から決して近づいてはならない場所が存在する。
> 文化祭の準備中、旧校舎の奥で発見された古びた扉。
> 好奇心に駆られた生徒たちが鍵を壊したその瞬間、**封印されていた呪い**が解き放たれた。
> 閉じ込められたあなたに残された時間はわずか。
> 館内に散りばめられた謎を解き明かし、この恐怖から生きて脱出せよ。

## 使い方（すぐ試す）

`index.html` をブラウザにドラッグ＆ドロップ（またはダブルクリック）するだけで動きます。

## 開発時チェック（自動検証）

ブラウザでの目視に加えて、レイアウト崩れ・文字の重なり・計時の挙動を自動チェックできます：

```bash
node scripts/verify.mjs
```

- **初回のみ** headless Chrome を自動ダウンロード（約 1〜2 分・計約 375MB）し `.cache/` に保存。**2回目以降はダウンロードなし**で即実行（約 13 秒）。
- 確認内容：横スクロールが出ない／開幕→2段階の扉→呪いの状態遷移／残り刻限 **15:00→14:59** の動作／クリック波紋がクリック点の中心から拡がる／タイマーと文字（端書き・物語・会場銘・落款）の重なりゼロ（デスクトップ 1440px ＋ スマホ 390px）。
- Node.js だけで動作（初回ダウンロード時のみネット必須）。`scripts/ensure-chrome.mjs` が単体でも冪等に動きます。
- `.cache/` は git 管理外（`.gitignore`）。削除すると次回実行時に再ダウンロードされます。

## GitHub Pages で公開 → Google Sites に埋め込む

**分ファイルのまま GitHub で公開できます**（`index.html` が `src/style.css`・`src/script.js` を参照。同じ相対パスが Pages でも通るので、リポジトリごと push するだけで動きます）。

1. このフォルダを GitHub リポジトリに push します。
2. リポジトリ設定 → **Pages** → Source: `Deploy from a branch` → ブランチ `main` / ルート を選択。
3. 数分後、`https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます。
4. Google Sites の対象ページで「挿入 → 埋め込み → 埋め込みコード」を選び、以下を貼り付けます：

```html
<iframe
  src="https://<ユーザー名>.github.io/<リポジトリ名>/"
  width="100%"
  height="100vh"
  style="border:0;"
  title="こっくりさんからの脱出"
</iframe>
```

> 推奨: Google Sites 側で iframe を**全画面サイズ（幅100%・高さ100vh）**にして表示すると、背景・文字が最も映えます。

## ★ 背景を差し替える方法

デフォルトの背景は **自作SVG（権利フリー・改変自由）** です。このまま商用利用・二次利用できます。

写真背景にしたい場合は、以下の2つのうち好きな方を選んでください。

**A. SVGを写真に置き換える（簡単）**
1. 著作権フリー（CC0 / Pixabay License / Unsplash License など）の写真を用意。
2. `index.html` 内、`<!-- 背景：自作ベクター -->` と書かれた `<svg id="bgScene" …>…</svg>` のブロック全体を削除。
3. 同じ場所に以下を貼る：

```html
<img id="bgScene" src="images/bg.jpg" alt=""
     style="position:fixed; inset:0; width:100%; height:100%; object-fit:cover; z-index:0;">
```

4. 画面が明るすぎる場合は、`<style>` 冒頭の `:root` の色変数、または `#blueNight` の黒いグラデーション濃度を上げて夜らしく調整します。

**B. SVGの中身だけ描き換える（上級）**
`<svg id="bgScene">` の中は「空 → 星 → 月 → 山 → 旧校舎 → 鳥居 → 枯れ木」の順で描かれています。不要な `<g>` を消し、自分の絵（`<path>` など）を足してください。

## ライセンス・権利メモ（重要）

- **背景イラスト**：このリポジトリで自作したベクター（SVG）＝権利クリーン。商用・改変ともに自由です。
- **フォント**：Google Fonts 配布の OFL フォントを使用。
- **画像の差し替え時**：Unsplash / Pixabay / Wikimedia Commons（CC0）など、ライセンス表示が不要または軽い素材を選んでください（とくに学校行事の掲示物では肖像権・著作権に注意）。
- ページ内の物語・演出はこの文化祭企画のオリジナルです。

> **単一HTMLが必要なとき**（オフライン配布 / Google Sites の「埋め込みコード」へ全文を貼る等）は `node scripts/build.mjs` を実行し、`dist/index.html` を1枚だけ使ってください。GitHub Pages での公開は **src/ 付きのまま**でOKです。
>
> **ページ間ナビゲーション**：どのページも左上の**ベル（鐘）**を押すと全ページの目次（入口／物語／本編／会場案内／スタッフ／結末）が開きます。移動時は左右から血幕が閉じて遷移します（ベルは P0 では従来の吊るし鐘、P1〜P5 では全站共通の小さめの鐘）。
